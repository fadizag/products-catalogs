# Products Catalogs

Flutter app for building Arabic RTL product datasets for supermarket and retail products.

Current scaffold includes dataset and product screens, local SQLite, barcode scanning/manual entry, product photo capture and JPEG optimization, and CSV import/export/share. This first commit has not been built or tested. Background removal and ZIP export that bundles images are planned, not yet implemented. See `docs/ROADMAP.md` for remaining work.
